# Emoji Catcher 🎮

Emoji Catcher ek simple aur fun frontend game hai jo HTML, CSS aur JavaScript ka use karke banaya gaya hai. In this game, aapko bucket ko left-right move karke achhe emojis (😃, 🍕, ❤️, etc.) catch karne hain aur bure emojis (💣, ☠️, 🔥, ⚠️) se bachna hai. Game ka UI responsive hai aur mobile par bhi achha kaam karta hai.

## Features

- Simple Gameplay: Use the left/right arrow keys or touch controls to move the bucket.

- Power-ups: Shield, slow-mo and magnet emojis catch karne par special effects milte hain.

- Score & High Score: Har sahi emoji par score badhta hai, high score local storage mein save hota hai.

- Daily Challenge: Roz ek target number of ❤️ emojis catch karne ka task milta hai.

- Leaderboard: Top 5 scores local device par show hote hain.

- Pause/Resume: Game ko pause aur resume kar sakte hain (P key ya button se).

- Sound & Theme: Sound mute/unmute aur Neon/Light theme toggle kar sakte hain.

- Share: Game ka link easily share kar sakte hain.

## Controls

- Arrow Keys: Left/Right move

- Touch: Drag your finger on the onscreen buttons for mobile devices.

- P: Pause/Resume

- Space: Start/Replay

- M: Mute/Unmute

- Theme Button: Neon/Light mode

- Share Button: Game link copy/share

## How to Play

1. Game start karne ke liye "Play" button dabayein.

2. Bucket ko left/right move karke achhe emojis catch karein.

3. Bure emojis se bachne ki koshish karein. Shield power-up milne par ek galat emoji se bach sakte hain.

4. Roz ka daily challenge complete karne ki koshish karein.

5. Apna high score aur leaderboard check karein.

## Tech Stack

- HTML5

- CSS3

- JavaScript (Vanilla)

## Local Storage Usage

- High score, leaderboard aur daily challenge progress browser ke local storage mein save hota hai. Isse aapka progress tab tak safe rahta hai jab tak aap browser ka data clear nahi karte.
